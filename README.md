# 社区共享厨房 · 值班安排

替代微信群登记的值班安排页，浏览器直接使用。

## 运行

```bash
node server.js        # 默认 http://localhost:3000，PORT=8080 可改端口
```

零依赖，Node 18+ 即可。数据保存在 `data.json`，重启不丢。

## 功能规则

- **登记**：选日期、时段（早餐/午餐/晚餐/夜宵）、灶台（1–4 号）、姓名。提交时若同一灶台同时段已被占用，返回 409 和该日**最新安排**，页面自动刷新。
- **开火**：登记后点「开火」进入开火中；已开火的记录被锁定，不能请假、不会被关闭当天影响。
- **替班**：临时有事 → 记录进入「待替班」；填写替班人姓名并交接后，登记人变更为替班人。未交接的计入「缺替班」。
- **关闭当天（管理员）**：未开始的登记（已登记/待替班）全部取消并显示关闭原因；开火中的记录保留。关闭后当天不可再登记，可重新开放（已取消记录保留原因便于追溯）。
- **汇总**：页面顶部按所选日期显示在册人数、开火中、缺替班、已取消数量。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/schedule?date=YYYY-MM-DD` | 查当天安排与汇总 |
| POST | `/api/bookings` | 登记 `{date, slot, stove, name}`，冲突返回 409 + 最新安排 |
| POST | `/api/bookings/:id/start` | 开火 |
| POST | `/api/bookings/:id/finish` | 结束使用 |
| POST | `/api/bookings/:id/leave` | 临时有事（进入待替班） |
| POST | `/api/bookings/:id/handover` | 交接 `{substitute}` |
| POST | `/api/days/:date/close` | 关闭当天 `{reason}` |
| POST | `/api/days/:date/open` | 重新开放 |

页面每 10 秒自动同步一次，多人同时用也能看到彼此的改动。
